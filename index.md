Orrery is a single-player 4X space opera with a living, agent-based economy. Space is a graph, time is real but pausable, and the whole thing is management-heavy on purpose. Unity 6 handles presentation; the simulation is plain C# that runs headless anywhere the dotnet SDK does.

The unusual part is how it's being built: a fleet of Claude agents implements, reviews, and merges the code, and I direct. This journal is the running commentary, written as it happens.

The repo itself is private for now, so issue and PR numbers in these posts are internal bookkeeping. Treat them like timestamps.
